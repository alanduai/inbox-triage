# inbox-triage

Private triage of Gmail (and later WhatsApp) messages into an Obsidian vault, with suggested replies reviewed in a local dashboard. Runs on a home Mac mini.

The same service runs the monthly expenses agent for Bea Nekretnine d.o.o.: it finds the receipts the accountant is missing and saves the reply to her, receipts attached, as a Gmail draft.

The code is in [`initial/`](initial/README.md); start there.
